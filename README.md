# Shtorka

Шаблоны сообщений для Telegram Desktop на Windows. Заголовок окна Telegram закрывает чёрная полоса «Шаблоны»; наведите на неё мышь — выпадет список названий. За полосу окно можно перетаскивать, как за обычный заголовок.

- клик по названию вставляет текст в открытый чат и закрывает список;
- двойной клик копирует текст в буфер обмена;
- правый клик открывает меню: вставить, скопировать, изменить, удалить;
- «+ Добавить шаблон» внизу списка создаёт новый.

Список закрывается сам, когда мышь уходит с него. Вкладка видна, пока Telegram открыт и активен, и никогда не закрывает кнопки управления окном.

## Установка

Скачайте `ShtorkaSetup.exe` со страницы [Releases](https://github.com/team-kontora/shtorka/releases/latest) и запустите. Программа ставится в `%LOCALAPPDATA%\Programs\Shtorka` только для вашей учётной записи, права администратора и Python не нужны.

Установщик не подписан, поэтому Windows при первом запуске может показать предупреждение SmartScreen: нажмите «Подробнее» → «Выполнить в любом случае».

Программа сидит в трее. В меню значка включите «Запускать вместе с Windows», чтобы вкладка появлялась без ручного запуска.

Удалить программу можно в «Параметры → Приложения → Установленные приложения». Шаблоны и настройки в `%APPDATA%\shtorka` при этом остаются.

## Обновления

Shtorka обновляется сама: через несколько секунд после запуска и затем каждые шесть часов она запрашивает у GitHub [последний релиз](https://github.com/team-kontora/shtorka/releases/latest), скачивает установщик новой версии, тихо запускает его и стартует заново. Шаблоны, настройки и автозапуск при этом сохраняются. Кроме этого запроса программа ничего не передаёт в сеть; отключить его можно настройкой `auto_update`. Текущая версия видна в подсказке значка в трее.

До версии 1.0.3 программа была одним файлом `Shtorka.exe`. Версия 1.0.2 сама переходит на установленную; 1.0.0 и 1.0.1 обновляться не умеют — поставьте `ShtorkaSetup.exe` вручную, старый файл после этого можно удалить.

## Шаблоны

Все шаблоны лежат в одном файле `%APPDATA%\shtorka\templates.json`. Он создаётся сам при добавлении первого шаблона.

Чтобы поделиться шаблонами, передайте коллеге свой `templates.json` — программа подхватит его без перезапуска. Файл можно править и вручную:

```json
[
  { "title": "Приветствие", "text": "Здравствуйте! Чем могу помочь?" }
]
```

## Оформление

Цвет и стиль шторки выбираются в меню значка в трее:

- «Цвет шторки» — готовые цвета или «Другой цвет…» с палитрой; пока палитра открыта, шторка сразу показывает выбранный цвет. Оттенки подсветки и цвет текста подбираются сами, так что на светлом фоне текст становится тёмным;
- «Стиль шторки» — прямоугольная или скруглённая (нижние углы полосы и списка скруглены).

Выбор запоминается в `config.json`.

## Настройки

Необязательный файл `%APPDATA%\shtorka\config.json` (появляется сам, когда вы меняете оформление, или создайте его вручную):

```json
{ "process_names": ["telegram.exe", "ayugram.exe"], "color": "#2b5278", "style": "rounded", "auto_update": true }
```


- `process_names` — имена процессов, за которыми следит шторка (если у вас неофициальный клиент Telegram, добавьте его сюда);
- `color` — цвет шторки в виде `#rrggbb`;
- `style` — `flat` (прямоугольная) или `rounded` (скруглённая);
- `auto_update` — `false` отключает автообновление.

## Запуск из исходников

Нужен Python 3.11+.

```powershell
git clone https://github.com/team-kontora/shtorka.git
cd shtorka
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pythonw run.pyw
```

При запуске из исходников `templates.json` лежит в папке проекта и не попадает в git.

Собрать установщик `dist\ShtorkaSetup.exe`: `.\build.ps1`. Нужен [Inno Setup](https://jrsoftware.org/isinfo.php): `winget install JRSoftware.InnoSetup`.

Выпустить обновление: поднимите `__version__` в `shtorka\__init__.py`, закоммитьте, запушьте и запустите `.\release.ps1`. Он соберёт установщик и опубликует релиз с тегом `v<версия>` (нужен [GitHub CLI](https://cli.github.com/)); запущенные копии подхватят его сами. Вместе с установщиком в релиз попадает однофайловый `Shtorka.exe`: через него на установленную версию переходят копии 1.0.2.

Проверки (их же запускает CI на каждый push и pull request):

```powershell
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\ruff check .
.venv\Scripts\pytest
```
